      Sync between devices

      Your apartments are stored in a secret GitHub Gist in your own account, so laptop and phone show the same list.

      1. Create a GitHub token with only the gist box ticked (choose an expiry, e.g. 90 days), then copy it.
      2. Paste it below and press Connect. Do the same on your other devices with the same token.

      The token is saved only in this browser and can only read/write your gists. You can revoke it any time on GitHub.

      Sync is on. Changes are saved to your secret gist automatically and picked up when you open the map on another device.
